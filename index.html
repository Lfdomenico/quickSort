    -Escolha do Pivô-

  1. Array original: [3, 14, 8, 10, 12, 5, 11, 9].

  2. O algoritmo "Quick Sort" é baseado em um técnica de divisão e conquista.

  3. Ele opera a partir de um array principal, dividindo-o em subarrays, por meio da escolha de um pivô. Esse pivô pode ser escolhido de algumas maneiras, como escolher o elemento[0] do array, o elemento[n-1] (último) de seu array, algum elemento intermediário, entre outras.

  4. No caso, como pivô, o 9 foi escolhido.

    5. -Particionamento do Array-

  5. Após a escolha do pivô, ele é comparado com os demais elementos constituintes do array, com o intuito de deixar aqueles à esquerda do pivô os valores menores que o pivô, e à direita os valores maiores que o pivô.

  6. Para isso, o index do pivô é fixado.

  7. O elemento do pivô é comparado com os demais elementos do início do array.

  8. Caso o elemento seja maior que o do pivô, seu index é reservado.

  9. O pivô permanece sendo comparado com os demais elementos. Caso um elemento menor que o pivô seja encontrado, ele terá seu posicionamento substituído pelo elemento maior que o pivô encotrado anteriormente.

  10. Esse processo é repetido até encontrar um elemento maior que o pivô, outro menor e alterar suas posições. Quando não encontrar, então o pivô é substituído pelo elemento fixado na interação ao percorrer o array.

    11. -Organização do SubArray

  11. Recursivamente, o mesmo processo é feito tanto para o array menor que o pivô ([3, 8, 5]) quanto para a parte maior que o pivô ([12, 14, 11, 10]).

  12. Em cada um desses subarrays, é definido um pivô, o array é percorrido com o intuito de deixar os elementos menores que o pivô do subarray à sua esquerda e os maiores à sua direita.
